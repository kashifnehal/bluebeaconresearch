Real-Time Geopolitical Risk Intelligence → Actionable Trading Signals

1. Landing Page & Access Gating (/)

Business Intent: Public entry point converting visitors into waitlist registrants or subscribers.

2. Tactical Intelligence Terminal (/dashboard)

Business Intent: Main hub for real-time conflict signal monitoring and market volatility analysis.

UI Features: Filter pills, Featured Critical Alert Banner (severity ≥ 8), Geopolitical Status Card, Market Drift Bar Chart, Recent Signal Feed, and Sentinel AI Sidebar.

3. Geopolitical Conflict Map (/map)

Business Intent: Full-canvas Mapbox GL GIS conflict heatmap visualizing global hotspots, troop movements, and maritime choke points.

UI Features: Interactive radar pins, Global Tension Index overlay, sentiment gauge, and floating market ticker.

4. Alert Rules & Webhooks (/alerts)

Business Intent: Mission control for setting up real-time notifications across Telegram, Slack, Webhooks, and Expo Mobile Push.

UI Features: Active rules list, 12-char Telegram connect code generator, Slack webhook manager, and REST Webhook signature keys.

5. Quantitative Backtesting (/backtesting)

Business Intent: Strategy simulator testing AI signal directional accuracy against historical commodity market movements.

6. User Settings & API Keys (/settings)

Business Intent: Profile settings, Stripe subscription management, and bb_live_... API key generation for Pro/API tier clients.
